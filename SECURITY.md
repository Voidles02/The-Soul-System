# Security Policy

## Supported Versions

Security updates are provided for the latest stable release of the plugin.

| Version                            | Supported          |
| ---------------------------------- | ------------------ |
| Latest stable                      | :white_check_mark: |
| Older releases                     | :x:                |
| Development / pre-release versions | :x:                |

If you are running an older version, please update to the latest stable release before reporting an issue that may already have been fixed.

## Reporting a Vulnerability

If you discover a security vulnerability, please **do not report it through a public GitHub issue**.

Instead, report it privately through **GitHub's Security Advisories** for this repository.

When reporting a vulnerability, please include as much of the following information as possible:

* A clear description of the vulnerability.
* The affected plugin version(s).
* The Minecraft and Paper versions affected.
* Steps to reproduce the issue.
* The expected behavior.
* The actual behavior.
* Any relevant error messages, logs, or stack traces.
* A proof of concept, if available and safe to provide.
* The potential impact of the vulnerability.

### What Happens After a Report?

After receiving a report, we will:

1. Review and investigate the reported vulnerability.
2. Attempt to reproduce and verify the issue.
3. Determine which versions are affected.
4. Develop and test a fix where necessary.
5. Release a patched version when appropriate.
6. Publish a security advisory when disclosure is appropriate.

Response and resolution times may vary depending on the severity and complexity of the vulnerability.

## Responsible Disclosure

Please allow reasonable time for the vulnerability to be investigated and, when necessary, patched before publicly disclosing technical details.

Please do not intentionally exploit vulnerabilities on servers you do not own or have explicit permission to test.

Security research should be conducted responsibly and should avoid:

* Accessing or exposing other users' data.
* Destroying or modifying server data.
* Disrupting server operation.
* Deploying malicious payloads.
* Exploiting the vulnerability against third-party servers without permission.

## Security Updates

Security fixes will be included in plugin releases when appropriate. Users are encouraged to keep the plugin updated and review the repository's release notes for security-related changes.

Thank you for helping keep the project and its users safe.
